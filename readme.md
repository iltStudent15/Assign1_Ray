# Personal Website

This project is a simple personal website built to present basic information about me, my interests, and my professional goals. The purpose of this repository is not only to host a small website, but also to demonstrate professional Git and GitHub workflow practices such as atomic commits, feature branching, pull requests, and clear project documentation.

## Project Purpose

The website serves as a personal online profile. It can include sections such as an introduction, skills, projects, contact information, and links to professional platforms. This project was intentionally kept small so the focus could remain on repository organization and version control discipline.

## Features

- Home page with personal introduction
- About or bio section
- Projects or skills section
- Contact or social links
- Clean and simple structure for easy updates
